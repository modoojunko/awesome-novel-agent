# 短篇正文格式规范

> 写正文前必读。只管交付排版：章节标记、段落形态、对话、标点、元信息禁令。
> 这是本仓短篇的默认交付格式；作者或目标平台另有明确要求时，以作者 / 平台要求覆盖。

## 章节标记

全文统一一种，不混用，且短篇小节**不带标题**（纯数字编号）：

| 格式 | 平台适用 | 示例 |
|------|----------|------|
| `###1.` | 短篇默认、红果、黑岩 | `###1.` `###2.` |
| `###第N章` | 番茄 / 七猫 / 古言篇幅较长时 | `###第一章` |
| `1.`（纯数字） | 知乎盐言 | `1.` `2.` |

## 段落：两套平台模板

先认平台底色，再按疏密原则分配字数；**不设统一的每段句数硬线**，长短交错才是活的。

### 黑岩：一句一段，留白快读

一句一段为主，多换行制造下坠感；单句成段是常态；节尾必留钩。

### 番茄 / 七猫：短段为底色，叙述交织对话

短段仍是底色，但允许多句回溯叙述段和对话交织；古言 / 世情可写更长的叙述段承载完整情绪链；爽点、打脸、反转处压短，过场一句带过。

### 两套共同的硬约束

- 正文相邻段落之间**只允许一个换行符 `\n`**，不得出现空行或连续换行（章节标记前后另算）
- **无缩进**（不用全角 / 半角空格缩进）
- **禁正文段落 Markdown**（除统一小节标记外，不用 `**` `*` `#` `---`）
- **段落形态上下限**（见 `.claude/knowledge/short-anti-ai.md` 第七节）：短段底色是下限；连续 3 段以上 3-5 字碎句且不在情绪峰值 = 电报体，回改

## 对话

- 引号：默认 `"说话内容"`（半角双引号）；知乎盐言或作者指定时用 `「」`，不要把 `「」` 当错误改掉
- 对话**独立成行**，不嵌在叙述段落里
- 用动作代替对话标签；普通的「说」按语境可留；两人连续对话省略标签
- 每句对话至少完成推动情节 / 揭示性格 / 制造冲突 / 埋设伏笔之一；连续多句仅寒暄或衔接的，删

## 标点硬约束

正文（含对话）统一不出现 `……` / `——` / `—` / `--`。停顿、哽咽、未尽、被打断、留白一律用短句、句号、逗号、动作 beat、换行实现。标点跟语气走：质问用问号；真爆点用 1 个感叹号，连续爆发最多 1-2 处；禁止通篇句号化。

## 禁正文混入元信息

正文叙述、对话、心理描写中不得出现：`第[一二三…]章`（指称自己的章节）、上一章、本章、前文、后文、伏笔、细纲、读者。要改成角色能感知的事件锚点或相对时间。例外：角色在故事世界内真实阅读 / 讨论「第 X 章」文本。

## 平台覆盖表

| 平台 | 章节标记 | 对话格式 | 段落底色 | 特殊要求 |
|------|----------|----------|----------|----------|
| 知乎盐言 | `1.`（纯数字） | `「」` | 短段 + 叙述交织 | 导语需单独打磨（150-220 字） |
| 番茄 | `###第N章` | `""` | 短段为底色，允许叙述交织对话 | 首段需有吸引力 |
| 红果 | `###1.` | `""` | 短段为底色 | 无 |
| 黑岩 | `###1.` | `""` | 一句一段，多换行留白 | 节尾必留钩 |

作者未指定平台时，默认短篇通用格式：`###1.` + `""` + 番茄系短段底色。

## 写完每段快速检查

- [ ] 段落形态符合目标平台模板？长短交错，没切成同一字数的提纲？
- [ ] 相邻段落之间只有一个 `\n`？
- [ ] 无缩进、正文无 Markdown？
- [ ] 对话独立成行、引号风格符合平台？
- [ ] 无禁用标点，停顿用短句 / 动作 / 换行？
- [ ] 每句对话有功能（推进 / 性格 / 冲突 / 伏笔）？
- [ ] 无元信息词？
