# generation-prompt-antiai Delta

## Purpose

为 prompt-crafter 组装生成提示词提供反 AI 注入增量：把统计分布锚、华美空洞防护、情绪清单禁与偏差表达、描写显形判据、对话位置密度知识注入写前提示词，使正文在生成阶段就带人味统计特征，而不是写完后靠清创补救。注入走既有通道与稀疏原则，生成与清创分离不变。

## ADDED Requirements

### Requirement: 统计节奏锚知识文件必须存在且通用化

知识文件 `knowledge/anti-ai/statistical-anchor.md` MUST 存在于仓库，并 MUST 被加入 `tools/init.py` 的 anti-ai 合并清单随部署产物下发。内容 MUST 满足：①覆盖五类锚，全部以**区间**表述——句长节奏（约每 4-7 句出现 1 个 ≤5 字碎句）、段落节奏（约每 6-10 段出现 1 个一句话段）、逗号密度（每段 0-4 个不等）、起句类型（连续 3 段不同类型）、关键名词不换说法（禁止同义词轮换）；②MUST 声明参数实例化原则：节奏锚是防均匀化的下限保护而非写作目标，具体参数是本章情绪曲线的因变量（紧张戏碎句密、舒缓戏长句慢），MUST 附情绪段→节奏倾向的参考映射表；③MUST NOT 使用「必须/不得低于/占比不低于」式硬配额、占比下限或全局固定点值（对齐 prompt-audit 维度 F 温感平衡口径）；④不含任何具体书名、人物名、检测器平台名、章节号；⑤不含与仓库现行标点口径冲突的建议（不建议插入省略号/破折号）；⑥不含视角混用条目（视角由章纲 POV 决定）；⑦开头声明实测来源为单书攻防经验，区间为默认值、按书与题材校准。

#### Scenario: 部署后可达
- **WHEN** `python tools/init.py` 初始化项目后读取部署产物 `.claude/knowledge/anti-ai.md`
- **THEN** 合并产物中包含统计节奏锚内容，`tools/check-agents.py` 校验通过（exit 0）

#### Scenario: 内容通用化验收
- **WHEN** 人工或脚本核对 `knowledge/anti-ai/statistical-anchor.md`
- **THEN** 五类锚齐备，全文无书名/检测器平台名/章节号，无省略号破折号建议与视角混用条目，开头带单书实测来源与按书校准声明

### Requirement: 节奏参数必须每章实例化，禁止跨章同参

prompt-crafter 组装提示词时 MUST 从知识文件的锚区间为**本章**取一组具体参数写进「质感要求」子节（本章节奏参数），取值 MUST 满足：①由本章情绪曲线与场景权重派生（按映射表：紧张/爆发段碎句取区间密端、舒缓/铺垫段取疏端），而非固定常量或无依据随机数；②与上一章提示词的节奏参数不同（读上一章 prompt 文件核对，连续两章同参即违反）；③全章倾向而非逐段配额——局部情绪段按写作方法论·叙事节奏交替反向变速时，以情绪段为准，节奏参数不得压制情绪变速。关键名词不换说法仍注入「输出·写作规范」为硬约束，对象限定为核心名词、术语、人名。节奏参数条 MUST 声明最低让步位（与红线/字数压缩/T1 词/认知动词/感官冲突时先让步，低权重压缩段豁免）与执行归属（倾向非硬规则），不出现自我引用。

#### Scenario: 提示词含本章参数且参数章章不同
- **WHEN** prompt-crafter 先后组装两章提示词
- **THEN** 每份提示词的质感要求子节各含一组本章节奏参数（区间内具体值），两组参数不全同，且各自的取值与该章情绪曲线方向一致（紧张章碎句密度高于舒缓章）

#### Scenario: 提示词含五类锚且归宿正确
- **WHEN** prompt-crafter 完成 `prompts/vol-{N}-ch-{M}-prompt.md` 组装
- **THEN** 质感要求子节含句长/段落/逗号/起句四类本章参数（带让步声明、无占比下限），写作规范段含关键名词不换说法（带对象限定）；参数未出现在不可违反规则列表

#### Scenario: 与既有节奏规则不跨源重复
- **WHEN** 通读组装后的提示词
- **THEN** 段落交替语义仅由既有「叙事节奏交替」定义一次，节奏参数只补句长/逗号/起句三类分布对象，未重复「禁止通篇等长段落」等既有语义（对齐 prompt-audit 维度 H 去重硬门禁）

#### Scenario: 情绪变速优先于参数
- **WHEN** 本章某高权重场景为爆发段，情绪节奏要求通篇短句
- **THEN** 该场景按情绪段写，节奏参数不作硬性约束（参数是全章倾向，局部以情绪段为准）

### Requirement: 华美空洞防护必须生成与清创两侧同源

`knowledge/anti-ai/common-rules.md` MUST 在 T1 新增华美空洞家族：①单句形容词堆叠（>3 个拆句）；②开篇连续环境/外貌描写堆砌（砍到两三笔）；③物理不通的华丽意象（意象必须真实可发生）。prompt-crafter 的 T1 简表注入通道 MUST 覆盖该家族。新增量化表述 MUST 通过 `tools/check-conflicts.py` 无冲突校验。

#### Scenario: 清创侧可扫
- **WHEN** anti-ai agent 按 common-rules T1 逐项清除
- **THEN** 华美空洞家族条目在 T1 表内，带「为什么禁 + 改成什么」，与既有阈值无冲突（check-conflicts.py exit 0）

#### Scenario: 生成侧可注入
- **WHEN** prompt-crafter 按 Step 1.6 注入 T1 最毒句式简表
- **THEN** 简表包含开篇描写限额与意象真实性约束，不整表搬运

### Requirement: 情绪清单禁、偏差表达与描写显形必须进入正向方法论

`knowledge/anti-ai/living-voice.md` MUST 新增三节正向原则（只增不删，不定义新阈值）：①情绪清单禁——禁止把复杂情绪列成清单，只写一个动作或一个细节；②偏差表达——人物反应必须属于「此人」（身份、身体习惯、当下要办的事），不同人遇同类情境不得用同一反应；③描写显形判据——写完一段描写自查「删掉它，人物还成立吗」，成立的描写让人显形，不成立的再华丽也是堆砌。prompt-crafter 注入的活人感正向要点 MUST 覆盖三者（每条 1-2 句精炼注入）。

#### Scenario: 正向方法论增补
- **WHEN** 核对 `living-voice.md` 与部署产物
- **THEN** 三节齐备，既有条目无删改（git diff 仅新增行），anti-ai.md 合并产物含三节

#### Scenario: 提示词含正向要点
- **WHEN** prompt-crafter 注入活人感正向要点
- **THEN** 提示词包含情绪清单禁、偏差表达、描写显形判据的精炼版，未引入新阈值

### Requirement: 对话位置密度知识必须增补且作者侧优先

`knowledge/anti-ai/structural-heat.md` MUST 在定律 2（对话密度）与定律 3（位置热值）内增补实测数据：句句带货时对白行占比 50-70% 为达标区、中段约 60-85% 位置内容对修改免疫（地板 0.55-0.68）、纯对话段安排在中段位置可让切片避开叙述块。增补 MUST 嵌入既有定律（不新增定律编号），沿用该文件「单书实测默认值、按文风与题材校准」与「作者侧优先于检测优化」的既有声明。prompt-crafter 在场景排序时 MAY 参考该知识，MUST NOT 将其写成硬性位置配额。

#### Scenario: 定律内增补
- **WHEN** 核对 `structural-heat.md`
- **THEN** 定律数量不变（仍为七条），定律 2/3 含新实测数据与校准声明，`tools/check-conflicts.py` exit 0

#### Scenario: 场景排序不作硬配额
- **WHEN** prompt-crafter 标注场景权重与顺序
- **THEN** 对话位置知识仅作排序参考出现（若有），作者章纲顺序冲突时以作者侧为准

### Requirement: 注入范围与生成清创分离约束不变

本次全部新增 MUST 通过既有注入通道落地（活人感正向要点 / T1 简表 / 写作规范 / 质感要求），MUST NOT 改变既有边界：疲劳词阈值、T2/T3 分级、二级禁用词不注入；writer 不边写边对照负面清单；prompt-crafting 的「组装后去重检查」与 Step 4 验收自检表「反AI注入范围」检查项 MUST 同步覆盖新增条目（新增节奏锚与既有节奏交替/句式交替规则按 prompt-audit 维度 H 口径不构成同格式重复）。

#### Scenario: 验收自检覆盖新增条目
- **WHEN** prompt-crafter 执行 Step 4 验收自检
- **THEN** 自检表「反AI注入范围」项包含统计节奏锚与正向要点新增条目，T2/T3 与疲劳词阈值仍不在注入范围

#### Scenario: 全链检查通过
- **WHEN** 运行 `tools/check-agents.py`、`tools/check-conflicts.py`、`tools/test_platforms.py`
- **THEN** 三者全部 exit 0，E2E 部署产物断言（如有）与合并产物内容一致
