# v4.10.0 版本说明

> **关键词：** #81 用户反馈全案修复、反AI规则源头治理、断点续跑、章节回滚、记忆闭环、Reasonix 支持

---

## 一句话

**这版围绕 GitHub issue #81 的真实用户反馈，把"写了很多设计但没起作用"的问题系统性收尾——规则不再互搏、中断不再从头跑、重写不再混设定、记忆真正影响写作，并新增 Reasonix（DeepSeek 前缀缓存优化）支持。** 多 agent 写作从"能跑"走向"可靠 + 省成本"。

---

## 这版做了什么

一位用户（bh15773496926）在 issue #81 里按严重性排列提了 8 条反馈，核心痛点是"框架写了很多设计、提示词和约束，但实际效果不行"——包括规则自相矛盾导致模型左右互搏、中断后从头跑、重写章节时新旧设定混用、记忆不起作用、成本偏高。这版把 8 条逐一定位根因并修复，每一轮修复都经过提示词工程师验证、再修复、再验证。

---

## 具体改了什么（6 件事）

| 改动 | 说明 |
|------|------|
| **反AI规则源头治理** | 破折号从"≤3次/章"数量线改为用法判定（few-shot 正反例）；统一 5 组跨文件冲突阈值（突然/竟然/似乎/对话密度/公式化副词）；职责声明烙进文件（common-rules=唯一权威）；新增 `check-conflicts.py` 在 CI 拦截阈值冲突和边界越界 |
| **Prompt 门禁（去重 + 重排）** | prompt-audit 新增维度 H（规则去重——同一语义只出现一次）+ 维度 I（优先级重排——利用 LLM 开头/结尾遵从度最高）；H/I 任一 FAIL 审计不通过，打回重新组装 |
| **断点续跑** | 写新章节 7 步流程全部支持断点续跑：章节状态记录当唯一断点源（省 token，不 Glob 扫文件）；writer 每段写 partial 草稿，中断后带 resume_from 续写不重头 |
| **章节回滚** | 重写某章时撤销该章归档追加（timeline 删行/foreshadowing 删钩子+回退收束/角色删状态块/章纲 status 回 outline）；作者说"重写第X章"即触发（#81-7 /undo） |
| **记忆闭环** | 作者偏好记忆注入 prompt 背景信息段（prompt-crafter 组装时读 writing-memory + permanent-memory）；updater 归档 diff 提取从"兜底"改"始终执行"，记录不依赖作者在场 |
| **知识部署断链修复** | sync-project.py 平铺 format-specs（原来保留子目录，导致 writer 写作基底等 7 个核心知识文件加载不到）；真实项目 20 条 agent 引用全部恢复 |

## 工程方法：验证闭环

这版延续了"改完测到没话说"的做法，且引入了更严格的验证：

1. **反AI规则治理**——`check-conflicts.py` 反向测试（注入冲突行/越界行确认能抓）
2. **断点续跑**——提示词工程师三轮验证，每轮抓到真问题（状态语义冲突、partial 死字段、落盘时机晚于崩溃），逐轮修复
3. **回滚**——真实项目数据副本演练（timeline 删行、foreshadowing 删钩子、角色块清零，且 ch1/ch2 完整保留）

## 兼容性保证

- ✅ 全新项目 `init.py` 初始化流程不变，自动带出全部新机制（含 .reasonix/skills/）
- ✅ 既有项目升级：`sync-project.py` 同步 agent/skill/知识库
- ✅ 写作流程本身（设定→卷纲→章纲→提示词→正文→去 AI 味→评审→归档）一脉相承，没变
- ⚠️ 真实项目 status.md 需手动补"当前章节进度"段（运行态文件，sync 不下发），断点续跑才生效

## 适合视频呈现的亮点

1. **一个 issue 带出的完整工程闭环** — 用户 8 条反馈 → 逐条定位根因 → 修复 → 提示词工程师验证 → 再修。每个"写了设计但没起作用"都找到了机制原因（如破折号被 4 套文档 3 套标准管着、写作基底根本没加载）。

2. **"省 token"的设计取舍** — 断点从 Glob 扫文件改为状态记录当权威；记忆注入 prompt 层而非 writer 直读（保持纯净上下文）；Reasonix 用前缀缓存治成本。每一处都是"靠机制不靠自觉"的延续。

3. **反AI规则的用法判定** — 破折号从"≤3次"数量线改为"删掉两侧内容意思是否变模糊"的用法判定 + few-shot 正反例，把"左右互搏"的根源（同一对象被多套标准管）根除。
