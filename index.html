世界观搭建 → 角色塑造 → 章节规划 → 正文写作，AI 全程陪你完成

18个题材正反例库，自动净化机器腔，检测句式重复，让文字更自然流畅

角色状态自动更新，写下一章时 AI 记得他的最新状态

连续高压/平淡过多时提醒你调整叙事节奏

🛠️ 多端支持

Claude Code、OpenCode、Reasonix、Codex 均可使用

快速安装

打开你的 AI 工具，对它说：

帮我安装 awesome-novel-skill，仓库在 https://github.com/modoojunko/awesome-novel-skill

AI 会自动运行准备好的安装脚本，把 skill 本体装好：

Claude Code ./install.sh claude-code OpenCode ./install.sh opencode Codex ./install.sh codex Reasonix 项目级部署（init.py --platform reasonix）

开始创作

安装完成后，在你想放小说项目的目录下启动 AI 工具，输入：

/awesome-novel

Codex 输入 /use awesome-novel，或直接说"帮我写本小说"。skill 会在本地自动初始化小说工作空间。
